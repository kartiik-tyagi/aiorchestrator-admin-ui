# Phase 7.5 — MI minutes: draft history, restore, compare

**Wave:** MI minutes (MoM document)  
**Depends:** 7.4; orchestrator **MI.39** Closed  
**Unlocks:** 7.6  
**Lock:** [PROGRAMME.md](./PROGRAMME.md); orchestrator doc 16 §3

---

## Operator outcome

I can see every saved state of the draft, open one, restore it, and compare any two versions (draft revisions or approved versions) to see exactly what changed.

---

## Goal

History drawer and Compare view on top of the MI.39 revisions API. Diffs are computed in the browser.

---

## In scope

### History (MoM tab toolbar → **History**)

- Drawer listing revisions newest first: version, source label (Generated / Edited / Restored / Before regenerate), time, counts.  
- Click → read-only `MinutesDocument` of that snapshot.  
- **Restore this version** → confirm `Modal` → `POST …/restore` with `expected_version`. Blocked while dirty.

### Compare (toolbar → **Compare**)

- Pick left and right from: current draft, any revision, any Official version.  
- Block diff: sections by id, decisions and actions matched by claim id; each block marked added / removed / changed / unchanged (collapsed).  
- Changed text shows a word-level diff (inserted/deleted marks).  
- Owner and due-date changes shown as field changes.  
- Utility `src/lib/textDiff.js`: word-level LCS, no new npm dependency.

---

- Diff of Summary / AI Feedback
