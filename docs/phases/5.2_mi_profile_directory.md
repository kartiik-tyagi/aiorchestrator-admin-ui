## In scope

### Routes / UI on `/MI/admin/profiles/:id`

| Section | Behaviour |
|---|---|
| **KB write token** | Optional `X-MI-KB-Token` field (password input); persist in `localStorage` key e.g. `orch_mi_kb_token` (same pattern as ingest token). Used for directory writes and later inbox. |
| **People CSV** | Choose file → upsert/import; dry-run if live API supports it; export download; show last result counts/errors in words. |
| **Products CSV** | Twin of people. |
| **Directory list** | Optional table from `GET /mi/v1/kb/entities?profile_id=&entity_type=person|product` — name + status; empty OK. |
| **Enable KG** | Button → `POST …/kg/enable`; show live `rules.kb.enabled` / resolve / extract after reload. Copy: “Applies to **new** jobs; meetings keep their snapshot.” |
| **Other docs** | Keep 3.2 paste/list; clarify label: standing library for Ask / background — **not** the people/products directory. |
