# Phase 2.4 — CC: polish + create-from-UI path

**Wave:** CC sync  
**Depends:** 2.1–2.3  
**Unlocks:** Wave 3 (CC considered sync enough to leave)  
**Lock:** [PROGRAMME.md](./PROGRAMME.md)

---

## Operator outcome

I can create a tiny inbound desk (one intent, one FAQ, one transfer) **only from this UI**, then smoke-test it. The console feels like one product, not a pile of forms.

---

## Goal

Close the CC operator loop and clean leftover pre-0.1 paths/copy. No new backend concepts.

---

## In scope

- **Dirty guards** on profile editor and flow builder (leave page / product switcher warns).
- **Empty states** in operator English:
  - No intents: “The bot can only follow edges you drew.”
  - No globals listed: “Global edges exist but are not armed on the flow.”
  - No retrieve keys on an Inform binding: “FAQ will only match questions, not intent/product.”
- Profile create: `product: call_center`, empty `intent_catalog`, default conversation_policy omitted (inherit kernel defaults).
- Flow scaffold: still a valid Entry→Speak→End; **no `cx`**; optional comment in UI that industrial fields are added in the builder.
- Tutorial + fieldGuide + README: paths `/CC/admin/…`; layout story is localStorage; mention intents / retrieve keys / no-cx.
- Optional prefetch `GET /v1/tenant/config` on Engines + Settings if it cuts duplicate calls (only if already added in 2.3).
- Destructive confirms already exist (delete profile/flow); keep them.
- Keyboard: do not steal builder shortcuts on other CC pages.

## Out of scope

- MI.
- New node types.
- Automated e2e suite (4.2 soak is human).

---

## Exit criteria

1. Create profile → draft → publish → binding (with retrieve keys) → flow (with one global or one intent edge) → pin → chat smoke test, **all from `/CC/admin`**, on **new** ids.
2. Refresh mid-edit on profile or builder warns.
3. Grep finds no leftover `to: '/engines'` (except redirects in 0.1).
4. Tutorial does not say Go ignores `cx`.
