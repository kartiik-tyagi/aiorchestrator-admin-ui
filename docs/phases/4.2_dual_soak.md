## Call Center checklist

Use **existing** live documents first (read-only / no-op saves), then a **new** tiny desk.

### A. Live documents unharmed

1. `/CC/admin` readiness matches reality (pin + published profile + published flow), not only server `ready_for_sessions`.
2. Open `coral-telecom-limited`, `coral-telecom-limited-outbound`, `coral-voice-desk` — industrial sections match `GET …/versions/latest` (catalog count, policy, audio, TTS if set).
3. No-op draft save on `coral-telecom-limited` — `intent_catalog` JSON identical (length and ids).
4. Open `coral-telecom-inbound` builder — **no** false Decide/global errors; interrupt / listen_policy / `global_intents` visible.
5. Save draft of inbound — GET draft has **no** `cx`.
6. Publish inbound only if you intend a new version; otherwise skip publish and still confirm validate `POST …/validate` returns 200 without `cx`.
7. Open `product-faq` — no-op save leaves `intents` / `department` / `product` / `aliases` intact.

### B. Create-from-UI (new ids only)

8. New profile `ui-soak-cc` with `product=call_center`, one intent, barge policy, publish.
9. New binding with retrieve keys; new flow (one listen + one Inform or one transfer); no `cx` on publish.
10. Pin + chat smoke test — greeting text appears; session stopped.
11. Delete order: pin → flow → profile (clean the lab).

### Fail immediately if

- Any live CC field is stripped.
- Flow publish 422s on `cx`.
- Bindings save drops retrieve keys.
- Validator still says Decide is unimplemented or globals are unused.

## Meeting Intelligence checklist

12. `/MI/admin` health up.
13. Create or reuse `ui-mi-demo` profile + one KB doc; GET matches the form.
14. New meeting + Case B fixture + transcript visible.
15. Draft ready (poll) → edit one field → version bump.
16. Approve preview + confirm (or document blocked by `unsupported_ai` with the field named — that is a **pass** of the gate).
17. Official GET + export download.
18. Meeting Ask: one cited answer **or** a clear abstain.
19. Session Ask: two turns survive reload.
20. Purge UI requires typed `PURGE` (do **not** run purge against production retention unless the owner says so — exercising the confirm disable is enough).
21. Ledger: hidden on 404 **or** lists open actions.

### Fail immediately if

- Approve ignores `unsupported_ai`.
- Ask invents an answer with empty citations and `abstained=false` when the server abstained (UI lie).
- MI pages call `/v1` CC APIs.
