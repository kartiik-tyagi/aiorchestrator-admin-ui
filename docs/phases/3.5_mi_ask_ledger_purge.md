# Phase 3.5 — MI: Ask + ledger-if-present + purge

**Wave:** MI  
**Depends:** 3.4 (Ask should prefer official; still works on draft-only if the server says so)  
**Unlocks:** 4.1  
**Lock:** [PROGRAMME.md](./PROGRAMME.md)

---

## Operator outcome

I can ask “what did we decide?” and see a citation — or a clear “not in the archive”. I cannot purge in one click.

---

## Goal

Meeting Ask and Profile Ask (one-shot **and** session thread). Action ledger only if the live binary has the routes. Retention purge behind a typed confirm. Case A lab buttons are stretch only.

---

## In scope

### Ask — one-shot

- Meeting: `POST /mi/v1/meetings/{id}/ask` `{ question }`
- Profile: `POST /mi/v1/profiles/{id}/ask` `{ question }`
- Render `answer`, `abstained`, `citations[]` (`kind`, `ref`, `snippet`)
- Abstain is **success-of-honesty** (not a red error): “Not in the official archive.”

### Ask — sessions (doc 08 §8.2 / MI.15)

- `POST …/ask/sessions` (meeting or profile) → session id
- `POST /mi/v1/ask/sessions/{id}/turns` `{ question }`
- `GET /mi/v1/ask/sessions/{id}` — ordered turns + citations
- UI: ChatGPT-style thread on meeting detail and profile detail. New session button. Do not pretend the vendor Think has memory — copy: “Each turn re-reads the archive.”

### Action ledger (probe)

If `GET /mi/v1/profiles/{id}/actions?status=open` returns 200:

- List open actions
- `POST …/actions/{action_id}/status` done/cancelled

If 404: **hide the section**. Do not fake data. Record the probe in `mi/client.js` comment (from 3.1).

### Retention purge

- Section only on `/MI/admin` settings-like card **or** a dedicated `/MI/admin/retention` — **not** a primary dashboard button.
- `POST /mi/v1/retention/purge` with whatever body the live API expects (read `retention_test.go` / handler — do not guess).
- Typed confirm string `PURGE`. Two-step: preview copy (“this deletes old transcripts per profile retention”) then confirm.
- Show purge counts from the response.

### Stretch (same phase only if leftover)

- Engineer-only disclosure: `POST …/media/lab-sfu` and `lab-mcu`.
- **Not** a default operator path. Media WS not required.

## Out of scope

- CC chat / inject.
- Inventing Ask evidence the server did not return.

## Exit criteria

1. One-shot and session Ask both work on an official meeting (or draft if that is all the lab has).
2. Abstain shows “not in the archive” plus empty citations.
3. Ledger hidden or working — never a dead form.
4. Purge cannot be clicked in one motion; confirm string required.
5. Stretch lab-sfu is behind an “Engineer” disclosure or absent.

---

## Verify

- Ask a question the MoM contains → citation.
- Ask nonsense → abstain.
- Open a session, two turns, reload `GET` session — both turns present.
- Purge UI: type `purge` (wrong) → stays disabled; type `PURGE` → enabled.
