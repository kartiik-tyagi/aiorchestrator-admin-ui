# Phase 7.3 — MI MoM tab: preview, in-place editing, save, draft download

**Wave:** MI minutes (MoM document)  
**Depends:** 7.2  
**Unlocks:** 7.4  
**Lock:** [PROGRAMME.md](./PROGRAMME.md); orchestrator doc 16 §4 OD-DOC-2/4/7

---

## Operator outcome

In the MoM tab I read the draft as a document, switch to Edit, fix sections, decisions and action items (text, owner, due date) in place, save, and download a watermarked draft PDF, all from one tab.

---

## Goal

Replace the form-style `DraftEditor` with the document workspace: Preview/Edit on `MinutesDocument`, saving through `useDraftWorkspace` (7.2), and Download for the draft.

---

## In scope

### Toolbar

- Status chip `Draft vN`; `Unsaved changes` chip when dirty; `Saved vN · hh:mm` after save.  
- **Preview | Edit** toggle (default Preview).  
- **Undo / Redo** (Ctrl+Z, Ctrl+Shift+Z / Ctrl+Y inside the tab), **Save** (Ctrl+S).  
- **Download ▾** (`DownloadMenu`, `draft: true`). While dirty it opens a `Modal`: **Save and download** / **Download last saved** / **Cancel** (OD-DOC-7).

### Edit mode on `MinutesDocument`

- **Sections:** title and body edit in place. Body editor is a plain textarea (OD-DOC-4) that is bullet-aware: Enter continues `- `, Backspace on an empty bullet removes it. Live count against 400 characters, over-limit shown in warn colour (allowed; the limit is the AI's, not a reviewer's).  
- **Decisions:** edit text; add; delete (confirm inline); move up/down.  
- **Actions:** table row editing: text; owner picker (attendees from transcript: `user_id` + `display_name`, plus free text); due date (`<input type="date">`, stored `YYYY-MM-DD`); add; delete; move up/down.  
- New claims get no id client-side; the server assigns it (MI.37).  
- Section ids are never created or renamed.

### Flags and evidence

- `unsupported_ai` claims show a red flag: "No transcript evidence. Edit or delete before approval." Outline rail shows the count.  
- Each claim with `span_text_snapshots` shows **N quotes ▾**; expanding lists speaker, time and quote, with **Open in Transcript** → `?tab=transcript&seg=<segment_id>` (Transcript tab scrolls to and highlights that segment).  
- Provenance badge per claim: AI grounded / Reviewer authored / Carried forward.

### Conflict and job states (from 7.2 hook)

- Conflict `Modal` shows mine vs theirs per changed block; **Keep mine** / **Take theirs**.  
- `job_in_progress`: toolbar banner; Save disabled until the job finishes.

### Clean-up

- Delete `src/pages/mi/DraftEditor.jsx`. Nothing else may edit the draft in the admin UI.

## UX

- Preview must be pixel-close to the PDF: same order, same labels, same watermark text.  
- The edit affordance is visible on hover/focus of each block. Keyboard: Tab moves between blocks; Esc leaves the block.  
- The `Refresh insights` bar and stale banner stay as today (5.4).

## Exit criteria

- [ ] Preview shows the draft as a document; Edit changes it in place  
- [ ] Owner and due date editable; add/delete/reorder work for decisions and actions  
- [ ] Changing one section body and saving leaves other claims' provenance badges unchanged (checks MI.37 end to end)  
- [ ] Undo/redo across ≥ 10 steps; Ctrl+S saves  
- [ ] Draft PDF downloads with `DRAFT – NOT APPROVED` on every page; dirty download prompts first  
- [ ] Quote expand + Open in Transcript highlights the segment  
- [ ] `DraftEditor.jsx` removed; lint clean; no CC edits

## Risks

- Undo history across a conflict resolution: clear the redo stack when "Take theirs" is chosen.  
- Large drafts (40+ actions): keep row editors light; no per-keystroke deep clone of the whole draft.
