# Phase 5.4 — MI meeting: Summary + AI Feedback + stale/refresh

**Wave:** MI memory + insights  
**Depends:** 5.3  
**Unlocks:** 5.5  
**Lock:** [PROGRAMME.md](./PROGRAMME.md), [WAVE_5_GAP.md](./WAVE_5_GAP.md)

---

## Operator outcome

On a meeting I can read **three surfaces**: MoM (truth I edit and approve), Meeting Summary (skim of this meeting), and AI Feedback (advice). Stale insights warn me; Refresh rebuilds Summary/Feedback without regenerating MoM.

---

## Goal

Meeting workspace panes for insights facet + refresh API (MI.33–MI.35). Trust classes stay visible and enforced in UI.

---

## In scope

### Meeting detail `/MI/admin/meetings/:id`

**Tabs or clearly separated panes:** `MoM` | `Summary` | `AI Feedback` (overview/transcript/approve/Ask remain as today).

| Pane | Source | Behaviour |
|---|---|---|
| **MoM** | Existing draft editor (3.4) | Edit + approve only here |
| **Summary** | `facet.insights.meeting_summary` | Read-only text/JSON render; empty state if missing/skipped |
| **AI Feedback** | `facet.insights.ai_feedback` | Read-only list of items + basis; **disclaimer**: “AI advice — not approved minutes.” Abstain/empty is OK |

### Stale + refresh

- From meeting GET facet: `insights.stale === true` → banner: insights behind draft version.  
- Button **Refresh insights** → `POST …/insights/refresh`.  
- Handle: `400 insights_disabled` → “Enable Summary or Feedback on the profile.”  
- `404` no draft → disable button with reason.  
- After refresh: reload facet (and draft version); clear stale when `source_draft_version` matches.  

### After PATCH draft (3.4)

- Reloading facets should show stale when insights lag (same as lab).

### Realtime (stretch, same phase if leftover)

- `EventSource` on `GET …/events` for `insights.updated` **or** keep poll-only (doc 08: poll sufficient for V1). Prefer poll first; SSE optional.

## Out of scope

- Writing Summary/Feedback into `PATCH` draft.  
- Showing Feedback on Approve wizard as a gate (approve must not block on stale insights).  
- Indexing advice into Ask.  
- Regenerating MoM from Refresh.

## Exit criteria

- [ ] With flags on and MoM ready, Summary and/or Feedback render from facet.  
- [ ] PATCH MoM → stale true until refresh.
