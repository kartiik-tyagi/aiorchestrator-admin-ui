## Goal

---

## In scope

**Remove (false):**

- Error: `Decide` nodes are not implemented.
- Warning: `kind=global` is never offered / unused.

**Add (true, matching Go):**

1. **`cx`** — if still present after 1.1 strip, error: layout is not part of the flow; remove `cx` (or rely on 1.1 wire-strip and still flag in the panel).
2. **Decide** — require `decide` object; `rules` non-empty; each rule `when` exactly one of `eq` / `in` / `exists`; `slot` set; `edge_id` is an outgoing edge; `else_edge_id` is an outgoing edge; slots must be declared ListenSlot keys or well-known keys (`active_language`, `preferred_language`, `department`, `ani`, `transfer_target`, `transfer_number`).
3. **ListenSlot** — require `slot` object; `key` matches `^[a-z][a-z0-9_]*$`; `validator` is `nonempty` | `enum` | `regex`; enum requires `enum[]`; regex requires `pattern`.
4. **`doc.globals`** — each id is an existing edge with `kind=global` and a non-empty `intent` or `option`; no duplicate matchers.
5. **`node.global_intents`** — each entry has a matching global edge matcher (case-insensitive).
6. **`node.allowed_intents`** — only on ListenChoice / ListenLanguage / ListenSlot; no blanks; no duplicates; globals must not be listed here (they belong in `global_intents`).
7. Keep existing: schema, entry, Inform binding_ref, prompt default_locale, matrix, transfer Tool, next/repair graph-shape checks that are UI-only (those stay as warnings/errors as today).

Closed lists: prefer `catalog` when a key exists later; until then, constants in `src/api/types.js` that copy Go.

## Exit criteria

1. Opening `coral-telecom-inbound` draft shows **no** Decide/global-unused false errors.
2. A fixture Decide without `decide.rules` **does** error.
3. A fixture ListenSlot without `slot` **does** error.
4. A fixture `globals: ["missing"]` **does** error.
5. A document with `cx: { layout: {…} }` **does** error (or 1.1 already stripped it before validate — then validate still errors if `cx` is present).
