# Phase 4.1 — Shared polish

**Wave:** Finish  
**Depends:** 2.4 and 3.5  
**Unlocks:** 4.2  
**Lock:** [PROGRAMME.md](./PROGRAMME.md)

---

## Operator outcome

Both products feel like one console family. I can switch CC ↔ MI without losing work silently. I never see Call Center words on an MI screen or the reverse.

---

## Goal

Unify chrome, empty/error/loading, product switcher dirty-awareness, and performance. No new product features.

---

## In scope

- Same dark theme, type scale, buttons, toasts, empty/error/loading for **both** shells (reuse `components/ui.jsx`; add 2–3 MI primitives only if missing).
- Product switcher always visible on both shells. If the current product has unsaved edits, confirm before leaving (CC profile/builder dirty from 2.4; MI profile/draft dirty from 3.2/3.4).
- Token box on both. **Tenant + engine status only on CC.** MI must not show “Ready for sessions” as if it were a DID.
- Keyboard: builder shortcuts (Ctrl+Alt+B, delete node, etc.) fire **only** on the flow builder route. MI meeting detail is forms — no canvas steal.
- Performance:
  - CC: catalog + platform status fetched once per `CcShell` mount (already CatalogProvider); do not remount provider on every CC child route.
  - MI: health + lists; honor `limit`/`cursor` if list responses include them; pause meeting poll when tab hidden (if not done in 3.3).
- Shared `ApiError` rendering: code + sentence from the product’s error map.
- README: one map of `/CC/admin` and `/MI/admin` for operators.
- Accessibility pass: labels on inspector/MI fields; focus visible; confirms on destructive actions.

## Out of scope

- New CC/MI fields.
- Embedding into the Go binary.
- Visual redesign / component library.

---

## Backend contract

None.

---

## Current baseline

- Shared `styles.css` + `ui.jsx` from the original CC-only app.
- Two shells from 0.1; dirty guards from 2.4 on CC only.

## UX

- Switcher labels: “Call Center” / “Meeting Intelligence” — not “CC” / “MI” in the bar (abbreviations OK in URLs only).
- Loading: skeleton or “Loading…” — never a flash of the other product’s dashboard.

## Exit criteria

1. Visual family matches (spacing, toasts, empty states) on `/CC/admin` and `/MI/admin`.
2. Dirty CC builder → switch to MI → cancel stays; confirm leaves.
3. Dirty MI draft → switch to CC → same.
4. No `/v1/meta/catalog` traffic on MI routes.
5. Builder shortcuts do not fire on `/MI/admin/meetings/:id`.
6. README documents both homes and `localhost:5183`.
